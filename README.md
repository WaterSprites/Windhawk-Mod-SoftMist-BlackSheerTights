# 柔雾黑丝 · Windows 11 美化风格包

让开始菜单、任务栏、通知中心、设置、右键菜单、文件资源管理器拥有一致的柔雾黑丝玻璃风格。浅色为柔雾，深色为黑丝；

此美化风格包，统一各款美化插件的默认数值标准，将原本需要分别配置、反复调试的独立插件，整合为一套风格协调、配置完整的美化方案，减少逐项调整的繁琐，让整套桌面更容易搭配和使用。并修复了前作者美化细节不足的问题。

解决了大部分美化效果过于透明从而看不清的视觉问题，解决了深色模式过深从而长时间使用视觉疲劳的问题。

让浅色模式更像柔雾的质感，深色模式更像黑丝的透感。保留文字、图标和必要的操作反馈，让不同系统界面放在一起不割裂更自然。



@WaterSprites (水妖)

本合集基于 Windhawk 本地 Mod 制作，各工具可以分别启用。开始菜单深浅模式共用一套背景；任务栏浅色仅略微提亮；右键菜单浅色沿用原有效果，其余组件分别适配深浅配色。

## 怎么使用

使用 Windows 11 和 Windhawk，在各工具的 `Mod` 文件夹中取用配套源代码与配置。

首次安装：创建本地 Mod，粘贴完整源码，编译并启用；更新已有版本时，同步导入配套 JSON 配置。不要同时启用作用于同一区域的原版与本地版。

各工具文件夹内都有一份简短的 `说明书.txt`，包含本版调整、安装更新与必要注意事项。 文件资源管理器的最终说明书位于该工具的 `设置/说明书.md`。

右键菜单美化额外依赖 TranslucentFlyouts 本体。已经一并附带在风格包中。



## 相对原作者的细节与补充

以下分别列出本套配色调整、样式修正与功能补充。原作者已有的玻璃主题、控件设计与样式框架继续保留；个人配色偏好不一概归为原作者缺陷。



### 开始菜单

- **深色效果**：深色菜单改用能够接受背景着色的亚克力效果。
- **背景参数**：深色使用 `#40606060`，与资源管理器的中性灰着色保持协调。
- **浅色效果**：恢复原有浅色效果及配置继承关系。
- **主题感知**：增加应用主题变化检查，自动切换浅色、深色配置。
- **沿用原版设计**：保留菜单圆角、阴影、尺寸、分隔线、动画及原有交互配置。



### 任务栏

- **主题资源**：为原先固定配色的任务栏增加浅色、深色主题资源。
- **深色效果**：保留原有玻璃观感，使用模糊 18、着色 `#25323232`。
- **浅色效果**：单独调整浅色背景，使用模糊 18、着色 `#25525252`，减少白色覆盖。
- **主题切换**：自动跟随 Windows 模式切换，避免浅色与深色模式外观没有变化。
- **输入法面板**：输入法切换面板保留模糊 25，并同步使用任务栏的浅色、深色着色。
- **沿用原版设计**：任务栏布局、尺寸、圆角、图标和原有按钮交互沿用当前配置。



### 任务栏通知中心

- **主面板**：统一通知中心、日历和音量／快速设置的柔雾黑丝背景。
- **背景参数**：主背景模糊强度为 20；浅色着色为 `#66F2F2F2`，深色着色为 `#40606060`。
- **通知卡片**：减轻重复底色叠加，降低卡片与主面板之间的反差。
- **主题色**：统一浅色、深色模式下的主题色规则，减少深色模式自动变为浅蓝灰的情况。
- **开关按钮**：补充快速设置子页面开关的主题色和圆点样式。
- **按钮反馈**：恢复并调整悬停、按下和选中后的颜色变化。
- **音量滑块**：补充音量滑块等快速设置控件的主题色与状态样式。
- **日历日期**：补齐当天与选中日期的状态配色，跟随当前主题色。



### 设置

- **主背景**：增加持续的浅色、深色玻璃背景，统一聚焦区与失焦区配色。
- **背景参数**：主背景模糊强度为 20；浅色着色为 `#66F2F2F2`，深色着色为 `#40606060`。
- **底色叠层**：减轻标题区、卡片、列表及展开内容的底色叠加。
- **导航图标**：统一单色线条图标，处理部分图标在选中状态下消失的问题。
- **搜索框**：调整普通与交互状态，减轻获得焦点时的背景突变。
- **浅色按钮**：降低白色填充反差，补充悬停和按下状态。
- **下拉选项**：统一浅色、深色下拉列表背景，使用模糊 20 和对应主窗口着色。
- **状态反馈**：保留系统主题色、选中指示、键盘焦点及悬停、按下反馈。
- **窗口边缘**：减轻部分窗口外框色边与合成区域的突兀感。



### 文件资源管理器

- **主背景**：增加柔雾黑丝系列全窗口玻璃配色，并适配应用深浅模式。
- **焦点反馈**：取消额外的失焦变暗遮罩，统一聚焦与失焦背景。
- **配套外观**：整合当前使用的液态玻璃控件风格，作为其他系列组件的配色参照。
- **主题感知**：增加全窗口背景着色与应用主题感知，调整深浅覆盖程度。
- **底色叠层**：提亮深色背景，处理部分顶部和文件区的叠层。
- **主题刷新**：统一聚焦与失焦背景，完善已打开窗口的主题刷新。
- **地址栏历史建议**：调整地址栏历史建议下拉框配色与遮挡程度。

- **配套整合**：整合配套液态玻璃控件，并补充中文简介与图文详情。
- **沿用原版设计**：圆角标签页、地址栏液态玻璃效果等沿用原作者已有设计，不列为本版从零新增的功能。

文本编辑右键菜单底色的 Alpha 为 100（十六进制 64），单层底色不透明度约为 39.2%；这一数值不代表整个菜单合成后的最终不透明度。地址栏层级下拉菜单的画刷不透明度、着色权重和亮度权重也是不同参数，不能合并理解为菜单整体透明度。

玻璃效果会受到壁纸、后方窗口和系统绘制方式影响，相同色值在不同区域的实际观感可能略有区别。



## 使用前了解

* 设置顶部可能保留极细黑线，本人能力有限，我实在无法修补这个BUG。
* 资源管理器地址栏下拉框目前没有有效模糊下方文件内容；资源管理器打开关闭窗口动画闪烁、部分原生绘制残留与分层仍有限制。
* 不同 Windows 版本与其他插件组合可能影响效果；更详细的说明见各工具说明书。建议系统版本不要超过25H2。



## 安装与使用

适用于 **Windows 11 64 位系统**，需要先安装 [Windhawk](https://windhawk.net/)。合集中的工具可以按需安装，无需全部启用。

1. 下载并解压本合集，在需要安装的工具文件夹中打开 `Mod` 文件夹。
2. 停用作用于同一区域的官方原版或旧版定制 Mod，避免样式冲突。
3. 在 Windhawk 中创建本地 Mod，将对应的 **“源代码.cpp”** 文件全部内容粘贴到源码编辑器，保存并编译。
4. 将配套 **“Mod.txt”** 文件的完整 JSON 内容导入该 Mod 的高级设置，保存并启用。
5. 关闭并重新打开对应界面，查看效果。安装其他工具时，重复以上步骤即可。

**右键菜单美化还需要安装并运行 TranslucentFlyouts 本体。** 本合集中的控制器负责应用配套设置，不能替代本体。



## 更新与恢复

* **更新本地版：** 先备份旧源码和配置，再替换新版源码、重新编译，并同步导入新版 Mod 配置。
* **恢复原版：** 停用本合集对应的本地 Mod，重新启用官方原版并恢复原配置。
* **恢复右键菜单：** 重新启用原控制器后，还需应用原配置；仅停用本地控制器不会自动撤销已经写入的设置。

源码与 Mod 配置请成对保存、成对使用。仅向官方原版导入配置，不能完整复现本套的代码定制效果。各工具的具体操作方法见对应文件夹中的 `说明书.txt` 和 `设置` 文件夹；文件资源管理器请参阅 `设置/说明书.md`。

## 不推荐的搭配与兼容性提醒

**使用本合集的文件资源管理器美化时，不建议同时启用 ExplorerBlurMica 或 DWMBlurGlass。**

根据本套配置的使用经验，叠加这些背景模糊工具可能引起资源管理器卡顿、响应变慢或背景显示异常。建议先停用它们，再启用柔雾黑丝资源管理器美化；这一提醒针对本套配置的搭配使用，并不代表它们在所有环境下都会出现问题。

同一界面也不建议同时启用官方原版 Styler、旧版定制 Styler和本合集对应的本地版，以免多套样式重复作用、相互覆盖。若出现卡顿或显示异常，可先停用其他作用于同一区域的背景、模糊或样式插件，再逐项检查。
