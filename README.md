# 柔雾黑丝 · Windows 11 美化风格包

让开始菜单、任务栏、通知中心、设置、右键菜单、文件资源管理器拥有一致的柔雾黑丝玻璃风格。浅色为柔雾，深色为黑丝；

此美化风格包，统一各款美化插件的默认数值标准，将原本需要分别配置、反复调试的独立插件，整合为一套风格协调、配置完整的美化方案，减少逐项调整的繁琐，让整套桌面更容易搭配和使用。并修复了前作者美化细节不足的问题。

解决了大部分美化效果过于透明从而看不清的视觉问题，解决了深色模式过深从而长时间使用视觉疲劳的问题。

让浅色模式更像柔雾的质感，深色模式更像黑丝的透感。保留文字、图标和必要的操作反馈，让不同系统界面放在一起不割裂更自然。



定制：水妖 / WaterSprites

本合集基于 Windhawk 本地 Mod 制作，各工具可以分别启用。开始菜单深浅模式共用一套背景；任务栏浅色仅略微提亮；右键菜单浅色沿用原有效果，其余组件分别适配深浅配色。

## 怎么使用

使用 Windows 11 和 Windhawk，在各工具的 `Mod` 文件夹中取用配套源代码与配置。

首次安装：创建本地 Mod，粘贴完整源码，编译并启用；更新已有版本时，同步导入配套 JSON 配置。不要同时启用作用于同一区域的原版与本地版。

各工具文件夹内都有一份简短的 `说明书.txt`，包含本版调整、安装更新与必要注意事项。

右键菜单美化额外依赖 TranslucentFlyouts 本体。已经一并附带在风格包中。

4. 补充搜索结果、热门应用、快速搜索和弹出菜单的低反差样式。

### 任务栏

3. 多次减少浅色背景的白色覆盖，保留接近深色的玻璃质感。
4. 输入法切换面板同步适配主题，并补充中文简介与图文详情。



### 任务栏通知中心

1. 统一通知中心、日历与快速设置的系列背景。

3. 统一深浅模式主题色规则，减少深色模式自动变为浅蓝灰的情况。
4. 补充 WLAN 等子页面开关的主题色与圆点样式。
5. 恢复并调整按钮悬停、按下、选中后的颜色变化。

玻璃效果会受到壁纸、后方窗口和系统绘制方式影响，相同色值在不同区域的实际观感可能略有区别。



## 使用前了解

* 设置顶部可能保留极细黑线，本人能力有限，我实在无法修补这个BUG。
* 资源管理器地址栏下拉框目前没有有效模糊下方文件内容；资源管理器打开关闭窗口动画闪烁、部分原生绘制残留与分层仍有限制。
* 不同 Windows 版本与其他插件组合可能影响效果；更详细的说明见各工具说明书。建议系统版本不要超过25H2。



## 安装与使用

适用于 **Windows 11 64 位系统**，需要先安装 [Windhawk](https://windhawk.net/)。合集中的工具可以按需安装，无需全部启用。

1. 下载并解压本合集，在需要安装的工具文件夹中打开 `Mod` 文件夹。
2. 停用作用于同一区域的官方原版或旧版定制 Mod，避免样式冲突。
3. 在 Windhawk 中创建本地 Mod，将对应的 **“源代码.cpp”** 文件全部内容粘贴到源码编辑器，保存并编译。
4. 将配套 **“Mod.txt”** 文件的完整 JSON 内容导入该 Mod 的高级设置，保存并启用。
5. 关闭并重新打开对应界面，查看效果。安装其他工具时，重复以上步骤即可。

**右键菜单美化还需要安装并运行 TranslucentFlyouts 本体。** 本合集中的控制器负责应用配套设置，不能替代本体。



## 更新与恢复

* **更新本地版：** 先备份旧源码和配置，再替换新版源码、重新编译，并同步导入新版 Mod 配置。
* **恢复原版：** 停用本合集对应的本地 Mod，重新启用官方原版并恢复原配置。
* **恢复右键菜单：** 重新启用原控制器后，还需应用原配置；仅停用本地控制器不会自动撤销已经写入的设置。

源码与 Mod 配置请成对保存、成对使用。仅向官方原版导入配置，不能完整复现本套的代码定制效果。各工具的具体操作方法见对应文件夹中的 `说明书.txt` 和 `设置` 文件夹。



## 推荐搭配

柔雾黑丝风格包主要统一系统界面的玻璃外观。搭配以下软件与 Windhawk Mod，可以进一步调整任务栏布局、动画和日常操作，让整套桌面的观感与使用体验更加协调。

这些都是可选搭配，按自己的使用习惯选择即可，无需全部安装。



### GitHub：

- **桌面小组件工具 uWidgets**
- **任务栏播放器 WaterSprite TaskbarMediaBar**

### Steam：

- **苹果菜单 MyDockFinder**
- **动态壁纸 Wallpaper Engine**

### Windhawk：

- **任务栏 Dock 悬停动画 Taskbar Dock Animation**
- **任务栏高度与图标大小 Taskbar height and icon size**
- **任务栏托盘图标间距调整 Taskbar tray icon spacing and grid**
- **任务栏托盘系统图标隐藏 Taskbar tray system icon tweaks**
- **任务栏应用独立音量调节 Taskbar Volume Control Per-App**
- **隐藏窗口边框 Invisible Window Borders**
- **移除焦点虚线框 No Focus Rectangle**
- **替换老式浏览文件夹弹窗 Modernize Folder Picker Dialog**
- **优化文件大小显示 Better file sizes in Explorer details**



布局类 Mod 建议逐项启用并调整，尤其是任务栏高度、图标大小和托盘间距，避免多项设置叠加后影响现有布局。实际兼容情况也会受到 Windows 版本和各 Mod 设置的影响。



## 不推荐的搭配与兼容性提醒

**使用本合集的文件资源管理器美化时，不建议同时启用 ExplorerBlurMica 或 DWMBlurGlass。**

根据本套配置的使用经验，叠加这些背景模糊工具可能引起资源管理器卡顿、响应变慢或背景显示异常。建议先停用它们，再启用柔雾黑丝资源管理器美化；这一提醒针对本套配置的搭配使用，并不代表它们在所有环境下都会出现问题。

同一界面也不建议同时启用官方原版 Styler、旧版定制 Styler和本合集对应的本地版，以免多套样式重复作用、相互覆盖。若出现卡顿或显示异常，可先停用其他作用于同一区域的背景、模糊或样式插件，再逐项检查。
